# Changelog — AccessScope VS Code / Cursor extension

## 1.0.8

- **Icona nella Activity Bar** con pannello AccessScope e pulsanti (come Android Studio).
- Comando **AccessScope: Open Panel** dalla Command Palette.
- Allineata al plugin Android Studio 1.0.8 (stesso CLI bundled).
- Risoluzione `adb` da SDK, `local.properties` e `ANDROID_SDK_ROOT`.
- Comandi **Clear Output**, **Check Extension Update**, **Install / Update** separato da Launch.
- Auto-detect `applicationId` da `app/build.gradle` per Fetch Results.
- Messaggi di errore migliorati (firma APK, adb mancante).

## 1.0.1

- Versione iniziale: select device, install+launch, fetch results, setup check.
