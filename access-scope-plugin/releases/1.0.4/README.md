# Release plugin Android Studio v1.0.4

## Installazione (solo questo file)

Scarica e installa **solo**:

### `AccessScope-1.0.4.zip`

**Settings → Plugins → Install Plugin from Disk…** → riavvia Android Studio.

Il file `AccessScope-cli.jar` è **già incluso dentro lo ZIP** (`AccessScope/lib/AccessScope-cli.jar`). Non serve scaricare altri file.

## Contenuto dello ZIP

```
AccessScope/
└── lib/
    ├── AccessScope-cli.jar          ← CLI bundled
    └── instrumented-android-studio-plugin-1.0.4.jar
```

## VS Code / Cursor

Usa la release in `releases/1.0.1/AccessScope-1.0.1.vsix` (o la VSIX nella GitHub Release dell'app).
