# Release plugin IDE v1.0.1

Compatibile con Android Studio **AI-261+** (`until-build` esteso a `999.*`).

| File | Uso |
|------|-----|
| `AccessScope-1.0.1.vsix` | VS Code / Cursor → *Extensions → Install from VSIX* |
| `AccessScope-1.0.1.zip` | Android Studio → *Settings → Plugins → Install from Disk* |
| `AccessScope-cli.jar` | CLI standalone (`java -jar AccessScope-cli.jar devices list`) |

L'APK dell'app AccessScope viene pubblicato nella GitHub Release dell'app (tag `v*` su `main`).
