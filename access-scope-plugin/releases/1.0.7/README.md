# Release plugin Android Studio v1.0.7

## Installazione

Scarica e installa **solo** `AccessScope-1.0.7.zip`:

**Settings → Plugins → Install Plugin from Disk…** → riavvia Android Studio.

## Novità UI

- **Cestino** — cancella l'area log del pannello AccessScope
- **Download** — verifica aggiornamenti plugin su GitHub; se disponibile, scarica e installa automaticamente (con riavvio IDE)

## Fix precedenti (1.0.5–1.0.6)

- Risoluzione percorso `adb` da SDK / `local.properties`
- Reinstall automatico su firma APK incompatibile
- Messaggi di errore migliorati
