# Release plugin IDE v1.0.1

Compatibile con Android Studio **AI-261+** (rimosso limite `until-build` 243).

Artefatti pronti per i colleghi (inclusi anche nella GitHub Release dell'app).

| File | Uso |
|------|-----|
| `AccessScope-1.0.0.vsix` | VS Code / Cursor → *Extensions → Install from VSIX* |
| `AccessScope-1.0.1.zip` | Android Studio → *Settings → Plugins → Install from Disk* |
| `AccessScope-cli.jar` | CLI standalone (`java -jar AccessScope-cli.jar devices list`) |

L'APK dell'app AccessScope viene pubblicato separatamente nella GitHub Release `v1.3.0` (non in questa cartella perché è in `.gitignore`).
