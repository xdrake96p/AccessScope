Contrasto Colore Insufficiente

Il testo dell'elemento non soddisfa i requisiti minimi di contrasto delle WCAG 2.1 Level AA. Questo rende il contenuto difficile o impossibile da leggere per utenti con disabilità visive.

Anteprima Visiva

visibility

Pulsante Azione

Inaccessibile
CORREZIONE SUGGERITA (4.6:1)

Pulsante Azione

Conforme AA
architecture

Azioni Correttive

1

Aumenta il rapporto di contrasto

Regola il colore del testo a #006875 per raggiungere un rapporto di 4.5:1.

2

Verifica la dimensione del font

Se il testo è inferiore a 18pt (24px), il rapporto deve essere superiore a 4.5:1.

3

Sostituisci lo sfondo

Utilizza una superficie solida invece di gradienti complessi per migliorare la leggibilità.

lightbulb

Pro Tip

L'uso di font più pesanti (bold) può compensare leggermente un contrasto marginale, ma non sostituisce la conformità WCAG.
